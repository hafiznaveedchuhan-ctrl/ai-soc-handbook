# Networking

* [Networking for SOC analysts — overview](networking-overview.md) - What a network is, how the networking pages in this handbook are organised, and why every alert a SOC analyst triages carries network evidence.
* [The OSI model](osi-model.md) - The seven layers of the OSI reference model, what each does, how they line up with the TCP/IP model, and how analysts use layer numbers when describing alerts.
* [The TCP/IP model and encapsulation](tcp-ip-model-and-encapsulation.md) - The four layers of the Internet protocol suite — application, transport, internet, link — what each provides, and how data is wrapped layer by layer on the way out.
* [Number systems: binary, decimal and hexadecimal](number-systems-binary-decimal-hex.md) - How the same value is written in binary, decimal and hexadecimal, how to convert between them, and where each notation appears in network data — IPv4 octets, MAC addresses, IPv6 groups and Windows hex fields.
* [Ethernet and MAC addresses](ethernet-and-mac-addresses.md) - How a 48-bit MAC address is built — vendor prefix, unicast versus multicast bit, global versus local bit — and the EtherType values that say what an Ethernet frame carries.
* [ARP — Address Resolution Protocol](arp.md) - How ARP maps an IPv4 address to a MAC address on the local network with a broadcast request and a reply, and why unexpected ARP changes matter to an analyst.
* [IPv4 addressing and the IPv4 header](ipv4-addressing.md) - What an IPv4 address is, the historical classes, and the IPv4 header fields an analyst meets in logs — TTL, protocol, flags, fragment offset, identification and length.
* [IPv4 subnetting and CIDR](ipv4-subnetting-and-cidr.md) - How CIDR prefix notation (/24, /26) defines a network, how to work out the mask, network address, broadcast address and usable hosts, and how to tell whether an address belongs to a subnet — with machine-checked examples.
* [Special-purpose IPv4 address ranges](special-ipv4-ranges.md) - The IPv4 blocks reserved for special purposes — private, shared (CGNAT), loopback, link-local, documentation, benchmarking, reserved and broadcast — and how to classify an address from an alert before looking it up.
* [IPv6 addressing](ipv6-addressing.md) - How an IPv6 address is written — eight 16-bit hex groups, leading-zero and double-colon compression, lowercase — the three address types, and machine-checked examples of the canonical short form.
* [Special-purpose IPv6 address ranges](ipv6-special-ranges.md) - The IPv6 blocks an analyst must recognise — loopback, unspecified, IPv4-mapped (::ffff:), link-local, unique-local, multicast and the documentation prefixes — and what each means in a log.
* [IPv6 Neighbor Discovery and SLAAC](ipv6-neighbor-discovery-and-slaac.md) - How IPv6 hosts find routers and neighbours with the five Neighbor Discovery messages (ICMPv6 133–137) and configure their own addresses with SLAAC — the IPv6 counterpart of ARP.
* [ICMP and ICMPv6](icmp-and-icmpv6.md) - What ICMP is for — error reporting and diagnostics — the type numbers analysts see most (echo, destination unreachable, time exceeded, redirect) for IPv4 and IPv6, and how they appear in alerts.
* [TCP — Transmission Control Protocol](tcp.md) - How TCP opens a connection with the three-way handshake, what each control flag means, the main connection states, and how SYN and RST patterns read in firewall and IDS logs.
* [UDP — User Datagram Protocol](udp.md) - What UDP is — connectionless datagrams with a four-field header — which common services use it, and why a UDP source address is weaker evidence than a completed TCP connection.
* [Ports and services](ports-and-services.md) - The three port ranges, the well-known ports a SOC analyst must recognise with IANA's official names, the IP protocol numbers, and the ports Wazuh itself uses.
* [Routing basics](routing-basics.md) - How a router picks the next hop — longest matching prefix, default route, static routes — what TTL does at each hop, and what that means for reading source addresses and traceroute-like ICMP in alerts.
* [Routing protocols overview — OSPF and BGP](routing-protocols-overview.md) - Interior versus exterior routing, what OSPF (link-state, IP protocol 89) and BGP (path-vector over TCP 179) do, their identifying numbers, and why unexpected OSPF or BGP traffic deserves a look.
* [NAT and PAT (NAPT)](nat-and-pat.md) - What Basic NAT and NAPT (port address translation) change in a packet, why one public address can stand for many internal hosts, the UDP mapping-timeout rule, and how NAT hides the real source in alerts.
* [VLANs and switching](vlans-and-switching.md) - What an 802.1Q VLAN tag is, the EtherType values that mark a customer (C-Tag) or service (S-Tag) VLAN tag, and why a VLAN is a separate network segment when reading logs.
* [DHCP and DHCPv6](dhcp.md) - How hosts get addresses — DHCP's DISCOVER/OFFER/REQUEST/ACK exchange on UDP 67/68, leases, the option numbers seen in logs, DHCPv6 on UDP 546/547 — and how DHCP logs map an IP back to a machine.
* [DNS — Domain Name System](dns.md) - How DNS works — names, records, recursive versus iterative resolution, UDP/TCP 53, response codes, reverse lookups — and what NIST SP 800-81r3 tells a SOC to log and watch for (tunnelling, exfiltration, protective DNS).
* [NTP and time synchronisation](ntp-and-time-sync.md) - How NTP keeps clocks in step — UDP 123, strata, the 1900 epoch and the 2036 wrap — RFC 8633's best practices (four sources, block control queries), and why correct time is the base of every timeline in triage.
* [Wireless (WLAN) basics for the SOC](wireless-basics.md) - What NIST SP 800-153 says about WLAN risk — dual-connected devices, rogue access points, passive versus active attacks, WIDPS sensors — and what that means when a wireless alert reaches triage.
* [HTTP and HTTPS](http-https.md) - What an HTTP request and response contain — method, target, status code, Host, User-Agent and Referer headers — the default ports 80 and 443, and how to read web and proxy log lines in an alert.
* [TLS — Transport Layer Security](tls.md) - What TLS gives a connection (server authentication, confidentiality, integrity), what TLS 1.3 encrypts and what stays visible (the ClientHello and its SNI), which versions are deprecated, and the TLS alerts seen in logs.
* [Email protocols — SMTP, IMAP, POP3, SPF, DKIM, DMARC](email-protocols.md) - How email moves (SMTP, submission, IMAP, POP3 and their ports), the difference between the SMTP envelope and the From header, Received trace lines, and how SPF, DKIM and DMARC results help judge a phishing alert.
* [Remote access protocols — SSH, RDP, Telnet](remote-access-protocols.md) - What SSH (TCP 22), RDP (TCP/UDP 3389) and Telnet (TCP 23) are, what each protects, how RDP logons appear as logon type 10, and how to triage remote-access attempts.
* [Firewalls](firewalls.md) - The firewall types in NIST SP 800-41r1 (packet filter, stateful inspection, application firewall, proxy gateway, WAF), deny-by-default, which addresses should never cross the perimeter, and what firewall logs tell an analyst.
* [IDS and IPS](ids-ips.md) - What intrusion detection and prevention systems do (NIST SP 800-94), the four IDPS types, signature versus anomaly versus stateful protocol analysis, inline versus passive sensors, false positives and negatives, and the encrypted-traffic blind spot.
* [Proxies and reverse proxies](proxies.md) - What forward proxies, reverse proxies (gateways) and tunnels are in HTTP, why a proxy hides the real client address, and how to read the Forwarded, X-Forwarded-For and Via headers without trusting them blindly.
* [VPNs and IPsec](vpn-and-ipsec.md) - How IPsec protects traffic — ESP (IP protocol 50), AH (51), transport versus tunnel mode, IKEv2 on UDP 500 and NAT traversal on 4500 — the VPN architectures in NIST SP 800-77r1, and what VPN logs give a SOC.
