# Networking

* [Networking for SOC analysts — overview](networking-overview.md) - What a network is, how the networking pages in this handbook are organised, and why every alert a SOC analyst triages carries network evidence.
* [The OSI model](osi-model.md) - The seven layers of the OSI reference model, what each does, how they line up with the TCP/IP model, and how analysts use layer numbers when describing alerts.
* [The TCP/IP model and encapsulation](tcp-ip-model-and-encapsulation.md) - The four layers of the Internet protocol suite — application, transport, internet, link — what each provides, and how data is wrapped layer by layer on the way out.
* [Number systems: binary, decimal and hexadecimal](number-systems-binary-decimal-hex.md) - How the same value is written in binary, decimal and hexadecimal, how to convert between them, and where each notation appears in network data — IPv4 octets, MAC addresses, IPv6 groups and Windows hex fields.
* [Ethernet and MAC addresses](ethernet-and-mac-addresses.md) - How a 48-bit MAC address is built — vendor prefix, unicast versus multicast bit, global versus local bit — and the EtherType values that say what an Ethernet frame carries.
* [ARP — Address Resolution Protocol](arp.md) - How ARP maps an IPv4 address to a MAC address on the local network with a broadcast request and a reply, and why unexpected ARP changes matter to an analyst.
* [IPv4 addressing and the IPv4 header](ipv4-addressing.md) - What an IPv4 address is, the historical classes, and the IPv4 header fields an analyst meets in logs — TTL, protocol, flags, fragment offset, identification and length.
* [IPv4 subnetting and CIDR](ipv4-subnetting-and-cidr.md) - How CIDR prefix notation (/24, /26) defines a network, how to work out the mask, network address, broadcast address and usable hosts, and how to tell whether an address belongs to a subnet — with machine-checked examples.
* [Special-purpose IPv4 address ranges](special-ipv4-ranges.md) - The IPv4 blocks reserved for special purposes — private, shared (CGNAT), loopback, link-local, documentation, benchmarking, reserved and broadcast — and how to classify an address from an alert before looking it up.
* [IPv6 addressing](ipv6-addressing.md) - How an IPv6 address is written — eight 16-bit hex groups, leading-zero and double-colon compression, lowercase — the three address types, and machine-checked examples of the canonical short form.
* [Special-purpose IPv6 address ranges](ipv6-special-ranges.md) - The IPv6 blocks an analyst must recognise — loopback, unspecified, IPv4-mapped (::ffff:), link-local, unique-local, multicast and the documentation prefixes — and what each means in a log.
* [IPv6 Neighbor Discovery and SLAAC](ipv6-neighbor-discovery-and-slaac.md) - How IPv6 hosts find routers and neighbours with the five Neighbor Discovery messages (ICMPv6 133–137) and configure their own addresses with SLAAC — the IPv6 counterpart of ARP.
* [ICMP and ICMPv6](icmp-and-icmpv6.md) - What ICMP is for — error reporting and diagnostics — the type numbers analysts see most (echo, destination unreachable, time exceeded, redirect) for IPv4 and IPv6, and how they appear in alerts.
* [TCP — Transmission Control Protocol](tcp.md) - How TCP opens a connection with the three-way handshake, what each control flag means, the main connection states, and how SYN and RST patterns read in firewall and IDS logs.
* [UDP — User Datagram Protocol](udp.md) - What UDP is — connectionless datagrams with a four-field header — which common services use it, and why a UDP source address is weaker evidence than a completed TCP connection.
* [Ports and services](ports-and-services.md) - The three port ranges, the well-known ports a SOC analyst must recognise with IANA's official names, the IP protocol numbers, and the ports Wazuh itself uses.
