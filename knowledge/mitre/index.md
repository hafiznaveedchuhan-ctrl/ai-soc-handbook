# Mitre

* [T1110 Brute Force](t1110-brute-force.md) - MITRE ATT&CK T1110 Brute Force — guessing or cracking credentials to get into accounts; its sub-techniques, how it shows up in Windows and Wazuh alerts, and what to look for.
* [T1110.001 Brute Force: Password Guessing](t1110-001-password-guessing.md) - MITRE ATT&CK T1110.001 Password Guessing — repeated password attempts against one account or a few accounts, the services it targets, and how the pattern appears in Windows failed-logon events.
* [T1110.003 Brute Force: Password Spraying](t1110-003-password-spraying.md) - MITRE ATT&CK T1110.003 Password Spraying — one or a few common passwords tried against many accounts to avoid lockouts; why it can slip under per-account and per-source thresholds, and what to look for.
* [T1110.004 Brute Force: Credential Stuffing](t1110-004-credential-stuffing.md) - MITRE ATT&CK T1110.004 Credential Stuffing — username/password pairs from unrelated breach dumps tried against your accounts; how it differs from guessing and spraying, and how 4625 failures from one source with many distinct pairs reveal it.
* [T1078 Valid Accounts](t1078-valid-accounts.md) - MITRE ATT&CK T1078 Valid Accounts — adversaries logging on with real, stolen or inactive credentials; why it looks like normal activity, and the logon patterns that give it away.
* [T1059.001 Command and Scripting Interpreter: PowerShell](t1059-001-powershell.md) - MITRE ATT&CK T1059.001 PowerShell — adversaries running commands and scripts through PowerShell; what to look for in process creation, command lines and PowerShell logging.
* [T1136.001 Create Account: Local Account](t1136-001-local-account.md) - MITRE ATT&CK T1136.001 Local Account — adversaries creating a local account to keep access; how it appears as event 4720 and as net user /add on the command line.
* [T1098 Account Manipulation](t1098-account-manipulation.md) - MITRE ATT&CK T1098 Account Manipulation — changing accounts or their group memberships to keep or raise access; including the sub-technique for adding accounts to local or domain groups, and how it appears as event 4732.
* [T1685.005 Disable or Modify Tools: Clear Windows Event Logs](t1685-005-clear-windows-event-logs.md) - MITRE ATT&CK T1685.005 Clear Windows Event Logs (formerly T1070.001) — adversaries wiping Windows event logs to hide their activity; the commands used and how it appears as event 1102.
* [T1053.005 Scheduled Task/Job: Scheduled Task](t1053-005-scheduled-task.md) - MITRE ATT&CK T1053.005 Scheduled Task — abusing Windows Task Scheduler for execution, persistence or privilege escalation; the log sources MITRE names (4698, 4702, Sysmon 1/11/13/14) and what makes a task suspicious.
* [T1543.003 Create or Modify System Process: Windows Service](t1543-003-windows-service.md) - MITRE ATT&CK T1543.003 Windows Service — creating or changing a Windows service so a payload runs at startup; the log sources MITRE names (4697, Sysmon 1/6/13/14) and how 7045 relates.
* [T1021.001 Remote Services: Remote Desktop Protocol](t1021-001-remote-desktop-protocol.md) - MITRE ATT&CK T1021.001 Remote Desktop Protocol — using valid accounts to log on over RDP and move laterally; the logon events MITRE correlates (4624, 4648, 4778, 4779) and what follows a suspicious RDP session.
* [T1003.001 OS Credential Dumping: LSASS Memory](t1003-001-lsass-memory.md) - MITRE ATT&CK T1003.001 LSASS Memory — reading or dumping lsass.exe memory to steal credentials; the Sysmon process-access signal (event 10, full access 0x1F0FFF) and the follow-on dump file MITRE correlates.
* [T1046 Network Service Discovery](t1046-network-service-discovery.md) - MITRE ATT&CK T1046 Network Service Discovery — scanning hosts for listening services (port, vulnerability, wordlist scans); the process + connection pattern MITRE correlates and how it shows up in firewall and flow logs.
* [T1548.002 Abuse Elevation Control Mechanism: Bypass UAC](t1548-002-bypass-uac.md) - MITRE ATT&CK T1548.002 Bypass User Account Control — elevating to high integrity without a UAC prompt via auto-elevated binaries and Registry tricks; the log sources MITRE names (4688, 4672, Sysmon 7/10/13/14).
* [T1685 Disable or Modify Tools](t1685-disable-or-modify-tools.md) - MITRE ATT&CK T1685 Disable or Modify Tools (formerly T1562.001) — stopping or tampering with EDR, antivirus, logging agents and sensors; the signals MITRE names (7045, Sysmon 5/13/14) and why missing telemetry is itself evidence.
* [T1566 Phishing](t1566-phishing.md) - MITRE ATT&CK T1566 Phishing — e-mailed or third-party messages with malicious attachments or links; the post-delivery signals MITRE correlates (new files, new processes, network activity) and the e-mail checks in this handbook.
